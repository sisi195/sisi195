## Featured Projects

### [MarketMind: Predicting Ad Performance](https://github.com/sisi195/Marketing-Optimization)

An end-to-end machine learning pipeline that analyzes consumer engagement with
online ads and predicts ad performance. Includes data cleaning across Power BI,
Excel, and Python, interactive Plotly visualizations, and tuned Random Forest
regression and classification models.

### [Content Response Prediction](https://github.com/sisi195/content-response-prediction)

A sentiment classification system built with Gradient Boosting. Combines text
preprocessing, feature selection with RFE, and class balancing with SMOTE to
predict how audiences respond to content.

### [Attention-Blitz: Patient Health Analysis](https://github.com/sisi195/Attention-Blitz)

A data analysis project exploring demographic patterns and health metrics,
including heart rate variability by gender, using Python for cleaning,
statistical analysis, and visualization.

### [SQL Business Insights](https://github.com/sisi195/sql-final-project1)

A SQL analysis project querying a relational business database to surface
insights on customers, sales, inventory, suppliers, and products.
